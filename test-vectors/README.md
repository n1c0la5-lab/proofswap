# Test vectors

Empty for now. Stagenet vectors will be generated by `scripts/gen-test-vectors.py`
with `monero-wallet-rpc` (milestone M1b) and committed here as JSON. Each vector
records Monero's own `check_tx_proof` verdict next to the result the verifier must
return.

Until then, `crates/proofswap-xmr-verify` is tested with Monero's own crypto test
vectors (`tests/data/`) and with synthetic vectors that the test code generates
itself. The synthetic ones are circular and are not a substitute for these.
